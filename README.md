## Dependencies

* python3
* numpy
* scipy
* python3-zmq
* python3-uhd
* pyadi-iio

### Installation on Ubuntu

```sudo apt install python3 python3-numpy python3-scipy python3-zmq python3-uhd uhd-host```

```pip install pyadi-iio```

### Installation on Fedora

```sudo dnf install python3 python3-numpy python3-scipy python3-zmq uhd uhd-devel```

```pip install pyadi-iio```

## Installing
